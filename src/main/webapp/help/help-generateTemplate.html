Shows a copy-and-paste-ready template, with the secret and substitution tokens in place, built from the configuration. On a job page it is built from the effective (merged) configuration as it stands in the editors, saved or not. On a global Config Set page it is built from the active version only, not from unsaved edits. Nothing is saved or changed by generating it.

The output is read-only; use Copy to clipboard to take the text. On a job page, Back to 3-panel view returns to editing.
