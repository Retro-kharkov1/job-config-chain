The content of this global Config Set. It is checked for syntax as you type, and a Save is refused while it is invalid. Every Save creates a new version; Save & Activate also makes that version the active one, which is what jobs that track the active version receive.

When jobs build on this Config Set, their overrides are applied on top of it. Arrays are replaced wholesale in that merge: a list in an override replaces this Config Set's list entirely and is never merged element by element.

Generate Template shows a copy-and-paste-ready template, with the secret and substitution tokens in place, built from the ACTIVE version only, not from unsaved edits. It is read-only and changes nothing.
