Cheia de configurare denumește un set de configurare global (comun) nou. Joburile se referă la el prin acest nume, în lanțul de bază al unui job și în argumentul configKey al pașilor de pipeline.

Setul de configurare este creat când îl salvați prima dată în editorul lui, nu când apăsați Deschide / Creează. Numele unui set de configurare șters rămâne rezervat până când este restaurat sau șters definitiv.
