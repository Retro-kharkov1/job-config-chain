Os conjuntos de configuração eliminados são mantidos, com todo o histórico de versões, para que uma eliminação possa ser anulada.

Assinale Mostrar eliminados para os listar. Restaurar devolve um conjunto de configuração ao serviço exatamente como estava. Eliminar permanentemente destrói-o juntamente com o histórico e não pode ser anulado; é recusado enquanto alguma tarefa ainda referir o conjunto de configuração.
