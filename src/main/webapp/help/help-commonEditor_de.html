Der Inhalt dieses globalen Konfigurationssatzes. Die Syntax wird während der Eingabe geprüft, und das Speichern wird verweigert, solange sie ungültig ist. Jedes Speichern erzeugt eine neue Version; Speichern & aktivieren macht diese Version zusätzlich zur aktiven, die Jobs erhalten, die der aktiven Version folgen.

Bauen Jobs auf diesem Konfigurationssatz auf, werden ihre Überschreibungen darüber angewendet. Arrays werden bei dieser Zusammenführung vollständig ersetzt: Eine Liste in einer Überschreibung ersetzt die Liste dieses Konfigurationssatzes komplett und wird nie elementweise zusammengeführt.

Vorlage generieren zeigt eine kopierfertige Vorlage mit den Secret- und Ersetzungs-Tokens an Ort und Stelle, erzeugt ausschließlich aus der AKTIVEN Version, nicht aus ungespeicherten Änderungen. Sie ist schreibgeschützt und ändert nichts.
