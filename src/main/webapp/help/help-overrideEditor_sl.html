Vsebina tega urejevalnika se uporabi povrh združenih osnovnih naborov konfiguracij. Zapišite samo to, kar se razlikuje od osnov; vsak izpuščen ključ se podeduje. V JSON in YAML nastavitev ključa na null odstrani ključ iz rezultata.

Polja se nadomestijo v celoti. Objekti se združujejo ključ za ključem, vendar se seznam (polje JSON, zaporedje YAML ali ponovljeni sorodni elementi v XML) nikoli ne združi element za elementom. Če ima osnova [1, 2, 3] in ta urejevalnik nastavi [4], je rezultat [4], ne [1, 2, 3, 4]. Če želite spremeniti en element seznama, tu ponovite celoten seznam.
