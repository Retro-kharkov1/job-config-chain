Попередній перегляд зведеного ланцюга базових наборів лише для читання, без власного перевизначення цього набору конфігурації. Він оновлюється під час редагування ланцюга базових наборів.

Масиви замінюються цілком: якщо два базові набори задають список, список пізнішого набору повністю замінює попередній; списки ніколи не поєднуються поелементно.
