Il contenuto di questo editor viene applicato sopra i set di configurazione di base uniti. Scrivi solo ciò che differisce dalle basi; ogni chiave omessa viene ereditata. In JSON e YAML, impostare una chiave a null la rimuove dal risultato.

Gli array vengono sostituiti per intero. Gli oggetti vengono uniti chiave per chiave, ma una lista (un array JSON, una sequenza YAML o elementi fratelli ripetuti in XML) non viene mai unita elemento per elemento. Se una base ha [1, 2, 3] e questo editor imposta [4], il risultato è [4], non [1, 2, 3, 4]. Per cambiare un solo elemento di una lista, ripeti qui l'intera lista.
