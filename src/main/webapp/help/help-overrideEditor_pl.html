Zawartość tego edytora jest stosowana na wierzchu scalonych bazowych zestawów konfiguracji. Zapisz tylko to, co różni się od baz; każdy pominięty klucz jest dziedziczony. W JSON i YAML ustawienie klucza na null usuwa go z wyniku.

Tablice są zastępowane w całości. Obiekty są scalane klucz po kluczu, ale lista (tablica JSON, sekwencja YAML lub powtórzone elementy rodzeństwa w XML) nigdy nie jest scalana element po elemencie. Jeśli baza ma [1, 2, 3], a ten edytor ustawia [4], wynikiem jest [4], a nie [1, 2, 3, 4]. Aby zmienić jeden element listy, powtórz tutaj całą listę.
