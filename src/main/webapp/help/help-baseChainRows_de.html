Die Zeilen sind die zusammengeführten Basis-Konfigurationssätze, von oben nach unten; eine spätere Zeile gewinnt, wo zwei Zeilen denselben Schlüssel setzen. Der eigene Inhalt dieses Konfigurationssatzes wird zuletzt auf das Ergebnis angewendet.

Konfigurationsschlüssel: der globale Konfigurationssatz, aus dem diese Zeile ihren Inhalt bezieht.

Modus: Aktiv folgt stets der aktuell aktiven Version dieses Konfigurationssatzes, sodass das Aktivieren einer neuen Version dort das Ergebnis hier ändert. Fixiert bindet die Zeile an eine bestimmte Version, die gleich bleibt, bis Sie die Fixierung ändern.

Fixierte Version: die im Modus Fixiert verwendete Versionsnummer. Im Modus Aktiv wird sie nicht verwendet.
