Afișează un șablon gata de copiat, cu tokenurile de secret și de substituție, construit din configurație. Pe pagina unui job este construit din configurația efectivă (îmbinată), așa cum se află în editoare, salvată sau nu. Pe pagina unui set de configurare global este construit doar din versiunea activă, nu din modificările nesalvate. Generarea nu salvează și nu modifică nimic.

Rezultatul este doar pentru citire; folosiți Copiază în clipboard pentru a prelua textul. Pe pagina unui job, Înapoi la vederea cu 3 panouri revine la editare.
