Les lignes sont les jeux de configuration de base fusionnés, de haut en bas ; une ligne suivante l'emporte lorsque deux lignes définissent la même clé. Le contenu propre à ce jeu de configuration est appliqué en dernier, par-dessus le résultat.

Clé de configuration : le jeu de configuration global dont cette ligne tire son contenu.

Mode : Actif suit toujours la version actuellement active de ce jeu de configuration, de sorte qu'activer une nouvelle version là-bas modifie le résultat ici. Épinglé fige la ligne sur une version, qui reste identique jusqu'à ce que vous changiez l'épinglage.

Version épinglée : le numéro de version utilisé en mode Épinglé. Il n'est pas utilisé en mode Actif.
