Vincula um valor secreto da configuração a uma credencial do Jenkins, de modo que o valor real nunca apareça no conjunto de configuração nem no histórico de versões dele.

Caminho com pontos: a localização do valor dentro do documento, com as chaves unidas por pontos, por exemplo database.password. Neste caminho, o editor só pode conter o espaço reservado literal __SECRET__; salvar qualquer outra coisa ali é rejeitado.

Credencial: a credencial do Jenkins que fornece o valor real quando um pipeline resolve a configuração. Apenas o ID da credencial é armazenado aqui, nunca o segredo em si. A lista mostra as credenciais disponíveis para os administradores do Jenkins.

Vincular credencial adiciona o caminho ou substitui a credencial se o caminho já estiver listado.
