Anteprima in sola lettura della configurazione finale: le basi unite con la tua sovrascrittura applicata sopra. È ciò che una pipeline riceve quando risolve questo set di configurazione.

Gli array vengono sostituiti per intero: una lista impostata nella sovrascrittura sostituisce completamente quella della base e non viene mai unita elemento per elemento. Se la sovrascrittura al momento non è valida, l'ultimo risultato valido resta visibile e viene contrassegnato come obsoleto.
