El contenido de este editor se aplica sobre los conjuntos de configuración base combinados. Escribí solo lo que difiere de las bases; toda clave que omita se hereda. En JSON y YAML, asignar null a una clave la elimina del resultado.

Los arrays se reemplazan por completo. Los objetos se combinan clave por clave, pero una lista (un array JSON, una secuencia YAML o elementos hermanos repetidos en XML) nunca se combina elemento por elemento. Si una base tiene [1, 2, 3] y este editor define [4], el resultado es [4], no [1, 2, 3, 4]. Para cambiar un elemento de una lista, repetí acá la lista completa.
