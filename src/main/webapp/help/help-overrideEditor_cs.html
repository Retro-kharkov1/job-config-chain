Obsah tohoto editoru se použije nad sloučenými základními sadami konfigurace. Zapište jen to, co se od základen liší; každý vynechaný klíč se zdědí. V JSON a YAML nastavení klíče na null odstraní klíč z výsledku.

Pole se nahrazují celá. Objekty se slučují klíč po klíči, ale seznam (pole JSON, sekvence YAML nebo opakované sourozenecké elementy v XML) se nikdy nesloučí prvek po prvku. Pokud základna má [1, 2, 3] a tento editor nastaví [4], výsledkem je [4], nikoli [1, 2, 3, 4]. Chcete-li změnit jeden prvek seznamu, zopakujte zde celý seznam.
