De inhoud van deze editor wordt bovenop de samengevoegde basisconfiguratiesets toegepast. Schrijf alleen op wat afwijkt van de bases; elke sleutel die u weglaat, wordt overgenomen. In JSON en YAML verwijdert het instellen van een sleutel op null die uit het resultaat.

Arrays worden in hun geheel vervangen. Objecten worden sleutel voor sleutel samengevoegd, maar een lijst (een JSON-array, een YAML- reeks of herhaalde elementen op hetzelfde niveau in XML) wordt nooit element voor element samengevoegd. Als een basis [1, 2, 3] heeft en deze editor [4] instelt, is het resultaat [4], niet [1, 2, 3, 4]. Om één element van een lijst te wijzigen, herhaalt u hier de hele lijst.
