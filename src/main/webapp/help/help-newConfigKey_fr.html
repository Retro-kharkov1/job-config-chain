La clé de configuration nomme un nouveau jeu de configuration global (commun). Les jobs s'y réfèrent par ce nom, dans la chaîne de base d'un job et dans l'argument configKey des étapes de pipeline.

Le jeu de configuration est créé lorsque vous l'enregistrez pour la première fois dans son éditeur, et non lorsque vous cliquez sur Ouvrir / Créer. Le nom d'un jeu de configuration supprimé reste réservé jusqu'à sa restauration ou sa suppression définitive.
