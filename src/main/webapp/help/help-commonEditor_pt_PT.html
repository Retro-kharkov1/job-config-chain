O conteúdo deste conjunto de configuração global. A sintaxe é verificada enquanto escreve, e a gravação é recusada enquanto for inválida. Cada gravação cria uma nova versão; Guardar e ativar torna também essa versão a ativa, que é a que as tarefas que seguem a versão ativa recebem.

Quando há tarefas construídas sobre este conjunto de configuração, as respetivas sobrescritas são aplicadas por cima. Nessa combinação, os arrays são substituídos por inteiro: uma lista numa sobrescrita substitui totalmente a lista deste conjunto de configuração e nunca é combinada elemento a elemento.

Gerar modelo mostra um modelo pronto para copiar e colar, com os tokens de segredo e de substituição no lugar, construído apenas a partir da versão ATIVA, não das edições não guardadas. É só de leitura e não altera nada.
