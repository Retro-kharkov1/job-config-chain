Las filas son los conjuntos de configuración base combinados, de arriba abajo; una fila posterior prevalece cuando dos filas definen la misma clave. El contenido propio de este conjunto de configuración se aplica al final, sobre el resultado.

Clave de configuración: el conjunto de configuración global del que esta fila toma el contenido.

Modo: Activa sigue siempre la versión activa actual de ese conjunto de configuración, de modo que activar allí una nueva versión cambia el resultado acá. Fijada congela la fila en una versión, que permanece igual hasta que cambies la fijación.

Versión fijada: el número de versión usado en modo Fijada. No se usa en modo Activa.
