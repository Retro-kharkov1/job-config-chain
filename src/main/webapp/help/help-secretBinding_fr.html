Lie une valeur secrète de la configuration à un identifiant Jenkins, de sorte que la valeur réelle n'apparaisse jamais dans le jeu de configuration ni dans son historique des versions.

Chemin à points : l'emplacement de la valeur dans le document, avec les clés jointes par des points, par exemple database.password. À ce chemin, l'éditeur ne peut contenir que l'espace réservé littéral __SECRET__ ; tout autre contenu est rejeté à l'enregistrement.

Identifiant : l'identifiant Jenkins qui fournit la valeur réelle lorsqu'un pipeline résout la configuration. Seul l'ID de l'identifiant est stocké ici, jamais le secret lui-même. La liste présente les identifiants disponibles pour les administrateurs Jenkins.

Lier l'identifiant ajoute le chemin, ou remplace l'identifiant si le chemin est déjà listé.
