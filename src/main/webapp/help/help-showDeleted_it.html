I set di configurazione eliminati vengono conservati, con l'intera cronologia delle versioni, così un'eliminazione può essere annullata.

Seleziona Mostra eliminati per elencarli. Ripristina rimette in servizio un set di configurazione esattamente com'era. Elimina definitivamente lo distrugge insieme alla sua cronologia e non può essere annullato; viene rifiutato finché un job cita ancora il set di configurazione.
