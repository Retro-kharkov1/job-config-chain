La chiave di configurazione dà il nome a un nuovo set di configurazione globale (comune). I job vi fanno riferimento con questo nome, nella catena di base di un job e nell'argomento configKey degli step della pipeline.

Il set di configurazione viene creato al primo salvataggio nel suo editor, non quando premi Apri / Crea. Il nome di un set di configurazione eliminato resta riservato finché non viene ripristinato o eliminato definitivamente.
