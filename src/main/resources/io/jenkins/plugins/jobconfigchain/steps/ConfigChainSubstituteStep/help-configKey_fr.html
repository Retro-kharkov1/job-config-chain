Nom d'un jeu de configuration global (commun) à résoudre directement, qu'il fasse ou non partie de la chaîne de base de ce job.

Valide uniquement avec Utiliser un jeu de configuration de base global ; sinon le build échoue. Le build échoue aussi si aucun jeu de configuration global ne porte ce nom. Un appel ne peut jamais atteindre la configuration propre d'un autre job.
