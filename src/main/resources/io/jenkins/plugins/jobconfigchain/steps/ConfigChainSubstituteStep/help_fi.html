Korvaa jokaisen kohdetiedoston #{Dotted.Path}#-tokenin sen arvolla tehokkaasta konfiguraatiosta ja kirjoittaa tiedoston takaisin. Salaiset arvot tulevat asetusjoukon salaisuuksien manifestiin sidotuista Jenkinsin tunnistetiedoista, eivät koskaan tallennetusta tekstistä.

Korvaus tehdään yhdellä läpikäynnillä: jokainen token korvataan kerran, eikä lisättyä tekstiä koskaan skannata uudelleen. Build epäonnistuu, jos token jää ratkaisematta tai sidottu tunnistetieto puuttuu. Onnistuessaan build tallentaa käyttöönottosidonnan (Deployment Binding) käytetyistä tarkoista versioista, jotta sama konfiguraatio voidaan toistaa myöhemmin valinnalla Ota uudelleen käyttöön ajosta.

Huomaa: kun konfiguraatioita asetetaan kerroksittain, päällimmäinen kerros korvaa JSON-taulukot kokonaan, eikä niitä koskaan yhdistetä alkio alkiolta.

Kutsu sitä Map-arvolla, esimerkiksi configChainSubstitute(file: 'app.json').
