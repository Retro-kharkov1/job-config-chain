Sellaisen yleisen (yhteisen) asetusjoukon nimi, joka ratkaistaan suoraan riippumatta siitä, kuuluuko se tämän työn perusketjuun.

Kelvollinen vain yhdessä asetuksen Käytä yleistä perusasetusjoukkoa kanssa; ilman sitä build epäonnistuu. Jos millään yleisellä asetusjoukolla ei ole tätä nimeä, build epäonnistuu myös. Kutsu ei voi koskaan päästä toisen työn omaan konfiguraatioon.
