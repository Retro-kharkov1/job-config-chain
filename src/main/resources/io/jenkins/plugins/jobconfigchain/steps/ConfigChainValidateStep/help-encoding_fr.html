Jeu de caractères utilisé pour lire le fichier cible, par exemple ISO-8859-1. Laissez vide pour le lire en UTF-8 ; si le fichier n'est pas en UTF-8 valide, l'étape consigne un avertissement et se rabat sur le jeu de caractères par défaut de l'agent, afin que les fichiers existants continuent de fonctionner. Une valeur explicite est stricte : ni repli ni avertissement, et un nom inconnu fait échouer le build.
