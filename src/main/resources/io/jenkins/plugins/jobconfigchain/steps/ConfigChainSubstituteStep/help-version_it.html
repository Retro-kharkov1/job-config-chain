Fissa un numero di versione esatto invece di quella attualmente attiva. Lascia vuoto per usare la versione attiva.

Senza Chiave di configurazione il numero è una versione della configurazione propria di questo job; con essa, una versione di quel set di configurazione globale. Una versione esplicita fa sì che questa chiamata ignori il Deployment Binding della build, così una deroga deliberata e occasionale non cambia mai ciò che la build registra.
