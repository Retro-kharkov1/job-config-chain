Sostituisce ogni token #{Dotted.Path}# nel file di destinazione con il suo valore dalla configurazione effettiva e riscrive il file. I valori segreti provengono dalle credenziali Jenkins collegate nel manifest dei segreti del set di configurazione, mai da testo memorizzato.

La sostituzione avviene in un solo passaggio: ogni token viene sostituito una volta e il testo inserito non viene mai riesaminato. La build fallisce se un token resta non risolto o se manca una credenziale collegata. In caso di successo la build registra un Deployment Binding delle versioni esatte usate, così la stessa configurazione può essere riprodotta in seguito con Ridistribuisci dall'esecuzione.

Nota: quando le configurazioni vengono sovrapposte, gli array JSON sono sostituiti per intero dal livello superiore e mai uniti elemento per elemento.

Chiamalo con una Map, ad esempio configChainSubstitute(file: 'app.json').
