Reemplaza cada token #{Dotted.Path}# del archivo de destino por su valor de la configuración efectiva y vuelve a escribir el archivo. Los valores secretos provienen de las credenciales de Jenkins vinculadas en el manifiesto de secretos del conjunto de configuración, nunca de texto almacenado.

La sustitución se hace en una sola pasada: cada token se reemplaza una vez y el texto insertado nunca se vuelve a examinar. La compilación falla si un token queda sin resolver o falta una credencial vinculada. Si tiene éxito, la compilación registra un Deployment Binding de las versiones exactas usadas, de modo que la misma configuración pueda reproducirse más tarde con Volver a desplegar desde la ejecución.

Nota: cuando se superponen configuraciones, la capa superior reemplaza por completo los arrays JSON y nunca se combinan elemento por elemento.

Llámelo con un Map, por ejemplo configChainSubstitute(file: 'app.json'). El nombre anterior configTemplateSubstitute sigue funcionando como alias obsoleto.
