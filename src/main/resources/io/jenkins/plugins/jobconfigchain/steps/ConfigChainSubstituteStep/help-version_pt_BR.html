Fixa um número de versão exato em vez da versão ativa atual. Deixe vazio para usar a versão ativa.

Sem Chave de configuração, o número é uma versão da configuração própria desta tarefa; com ela, uma versão desse conjunto de configuração global. Uma versão explícita faz com que esta chamada ignore o Deployment Binding do build, de modo que uma exceção pontual deliberada nunca altere o que o build registra.
