Διαδρομή του αρχείου διαμόρφωσης προορισμού, σχετική με τον χώρο εργασίας του build. Υποχρεωτικό: δώστε το εδώ ή σε προηγούμενη κλήση setupConfigChain στο ίδιο build.

Ένα αρχείο εκτός του χώρου εργασίας δεν απορρίπτεται· το βήμα γράφει μια προειδοποίηση στο αρχείο καταγραφής του build και συνεχίζει.
