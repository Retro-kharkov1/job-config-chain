Διαδρομή του αρχείου διαμόρφωσης προορισμού, σχετική με τον χώρο εργασίας του build. Αποθηκεύεται για τις μεταγενέστερες κλήσεις configChainValidate και configChainSubstitute σε αυτό το build, οι οποίες μπορούν τότε να το παραλείψουν· μια τιμή που δίνεται σε αυτές τις κλήσεις υπερισχύει. Ένα αρχείο εκτός του χώρου εργασίας προκαλεί μόνο προειδοποίηση στο αρχείο καταγραφής του build.
