Conjunto de caracteres utilizado para ler o ficheiro de destino e voltar a gravá-lo, por exemplo ISO-8859-1. Deixe vazio para utilizar UTF-8; se o ficheiro não for UTF-8 válido, o passo regista um aviso, recorre ao conjunto de caracteres predefinido do agente e volta a gravá-lo nesse mesmo conjunto. Um valor explícito é estrito: sem recurso alternativo nem aviso, e um nome desconhecido faz o build falhar. Uma marca de ordem de bytes não é adicionada nem removida.
