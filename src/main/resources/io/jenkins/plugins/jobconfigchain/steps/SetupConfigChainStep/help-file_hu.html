A célkonfigurációs fájl elérési útja a build munkaterületéhez képest. Eltárolódik a build későbbi configChainValidate és configChainSubstitute hívásai számára, amelyek ekkor kihagyhatják; az ezekben a hívásokban megadott érték élvez elsőbbséget. A munkaterületen kívüli fájl csak figyelmeztetést eredményez a build naplójában.
