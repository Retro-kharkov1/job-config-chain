Substitui cada token #{Dotted.Path}# no ficheiro de destino pelo respetivo valor da configuração efetiva e volta a gravar o ficheiro. Os valores secretos provêm das credenciais do Jenkins associadas no manifesto de segredos do conjunto de configuração, nunca de texto armazenado.

A substituição é feita numa única passagem: cada token é substituído uma vez e o texto inserido nunca é examinado de novo. O build falha se um token ficar por resolver ou se faltar uma credencial associada. Em caso de sucesso, o build regista um Deployment Binding das versões exatas utilizadas, para que a mesma configuração possa ser reproduzida mais tarde com Voltar a implementar a partir da execução.

Nota: quando as configurações são sobrepostas, os arrays JSON são substituídos por inteiro pela camada superior e nunca combinados elemento a elemento.

Chame-o com um Map, por exemplo configChainSubstitute(file: 'app.json'). O nome anterior configTemplateSubstitute continua a funcionar como alias obsoleto.
