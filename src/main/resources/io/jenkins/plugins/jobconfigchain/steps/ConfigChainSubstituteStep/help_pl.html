Zastępuje każdy token #{Dotted.Path}# w pliku docelowym jego wartością z efektywnej konfiguracji i zapisuje plik z powrotem. Wartości sekretów pochodzą z poświadczeń Jenkinsa powiązanych w manifeście sekretów zestawu konfiguracji, nigdy z zapisanego tekstu.

Podstawianie odbywa się w jednym przebiegu: każdy token jest zastępowany raz, a wstawiony tekst nie jest ponownie skanowany. Budowanie kończy się błędem, jeśli token pozostaje nierozwiązany lub brakuje powiązanego poświadczenia. Po sukcesie budowanie zapisuje powiązanie wdrożenia (Deployment Binding) z dokładnymi użytymi wersjami, dzięki czemu tę samą konfigurację można później odtworzyć za pomocą opcji Wdróż ponownie z uruchomienia.

Uwaga: gdy konfiguracje są nakładane warstwowo, tablice JSON są w całości zastępowane przez nakładkę i nigdy nie są scalane element po elemencie.

Wywołaj go z mapą, na przykład configChainSubstitute(file: 'app.json'). Dawna nazwa configTemplateSubstitute nadal działa jako przestarzały alias.
