Egy korábbi build telepítéséhez használt konfiguráció újrajátszása visszaállítás céljából: ennek a feladatnak egy buildszáma, vagy <feladat teljes neve>#<buildszám>. Hagyja üresen a szokásos telepítéshez.

Az eredmény bájtról bájtra megegyezik az adott build kimenetével, akkor is, ha az alap konfigurációs készletek azóta változtak. Ha ahhoz a buildhez nincs rögzített telepítési kötés (Deployment Binding), a lépés ezt jelzi a build naplójában, és hiba helyett a feladat élő konfigurációját használja.
