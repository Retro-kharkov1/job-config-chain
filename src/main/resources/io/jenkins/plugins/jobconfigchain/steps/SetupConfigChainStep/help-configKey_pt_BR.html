Nome de um conjunto de configuração global (comum) a ser resolvido diretamente, faça ele parte ou não da cadeia base desta tarefa.

Válido somente junto com Usar um conjunto de configuração base global; sem isso, o build falha. O build também falha se nenhum conjunto de configuração global tiver esse nome. Uma chamada nunca pode alcançar a configuração própria de outra tarefa.
