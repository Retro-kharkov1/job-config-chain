Rejouer la configuration avec laquelle un build antérieur a été déployé, pour un retour en arrière : un numéro de build de ce job, ou <nom complet du job>#<numéro de build>. Laissez vide pour un déploiement normal.

Le résultat est identique octet pour octet à la sortie de ce build, même si les jeux de configuration de base ont changé depuis. Si ce build n'a pas de Deployment Binding enregistré, l'étape le signale dans le journal du build et utilise la configuration actuelle de ce job au lieu d'échouer.
