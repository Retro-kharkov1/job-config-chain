Ersetzt jedes #{Dotted.Path}#-Token in der Zieldatei durch seinen Wert aus der effektiven Konfiguration und schreibt die Datei zurück. Secret-Werte stammen aus den Jenkins-Zugangsdaten, die im Secrets-Manifest des Konfigurationssatzes gebunden sind, nie aus gespeichertem Text.

Die Ersetzung erfolgt in einem Durchgang: Jedes Token wird einmal ersetzt, und eingefügter Text wird nie erneut durchsucht. Der Build schlägt fehl, wenn ein Token unaufgelöst bleibt oder gebundene Zugangsdaten fehlen. Bei Erfolg zeichnet der Build eine Deployment Binding der exakt verwendeten Versionen auf, sodass dieselbe Konfiguration später mit Erneut bereitstellen aus Lauf wiederholt werden kann.

Hinweis: Beim Schichten von Konfigurationen werden JSON-Arrays vom überlagernden Inhalt vollständig ersetzt und nie elementweise zusammengeführt.

Aufruf mit einer Map, zum Beispiel configChainSubstitute(file: 'app.json'). Der frühere Name configTemplateSubstitute funktioniert weiterhin als veralteter Alias.
