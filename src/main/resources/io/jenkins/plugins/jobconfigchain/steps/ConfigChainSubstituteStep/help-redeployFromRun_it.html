Riproduce la configurazione con cui è stata distribuita una build precedente, per il rollback: un numero di build di questo job, oppure <nome completo del job>#<numero di build>. Lascia vuoto per una distribuzione normale.

Il risultato è identico byte per byte all'output di quella build, anche se nel frattempo i set di configurazione di base sono cambiati. Se quella build non ha un Deployment Binding registrato, lo step lo segnala nel log della build e usa la configurazione attuale di questo job invece di fallire.
