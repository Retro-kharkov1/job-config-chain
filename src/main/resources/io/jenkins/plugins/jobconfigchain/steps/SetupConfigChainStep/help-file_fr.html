Chemin du fichier de configuration cible, relatif à l'espace de travail du build. Il est mémorisé pour les appels ultérieurs à configChainValidate et configChainSubstitute dans ce build, qui peuvent alors l'omettre ; une valeur fournie lors de ces appels l'emporte. Un fichier situé en dehors de l'espace de travail ne produit qu'un avertissement dans le journal du build.
