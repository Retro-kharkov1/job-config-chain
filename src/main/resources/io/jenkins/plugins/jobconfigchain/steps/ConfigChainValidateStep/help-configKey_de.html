Name eines globalen (gemeinsamen) Konfigurationssatzes, der direkt aufgelöst werden soll, unabhängig davon, ob er zur Basiskette dieses Jobs gehört.

Nur zusammen mit Globalen Basis-Konfigurationssatz verwenden gültig; ohne diese Option schlägt der Build fehl. Der Build schlägt ebenfalls fehl, wenn kein globaler Konfigurationssatz diesen Namen trägt. Ein Aufruf kann nie die eigene Konfiguration eines anderen Jobs erreichen.
