Reproduce la configuración con la que se desplegó una compilación anterior, para revertir: un número de compilación de este trabajo, o <nombre completo del trabajo>#<número de compilación>. Dejalo vacío para un despliegue normal.

El resultado es idéntico byte a byte a la salida de esa compilación, incluso si los conjuntos de configuración base han cambiado desde entonces. Si esa compilación no tiene un Deployment Binding registrado, el paso lo indica en el registro de la compilación y usa la configuración actual de este trabajo en lugar de fallar.
