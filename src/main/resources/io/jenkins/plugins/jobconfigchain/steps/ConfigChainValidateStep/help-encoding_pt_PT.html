Conjunto de caracteres utilizado para ler o ficheiro de destino, por exemplo ISO-8859-1. Deixe vazio para o ler como UTF-8; se o ficheiro não for UTF-8 válido, o passo regista um aviso e recorre ao conjunto de caracteres predefinido do agente, para que os ficheiros existentes continuem a funcionar. Um valor explícito é estrito: sem recurso alternativo nem aviso, e um nome desconhecido faz o build falhar.
