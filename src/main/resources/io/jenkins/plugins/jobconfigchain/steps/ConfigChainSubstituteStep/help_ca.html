Substitueix cada token #{Dotted.Path}# del fitxer de destinació pel seu valor de la configuració efectiva i torna a escriure el fitxer. Els valors secrets provenen de les credencials de Jenkins vinculades al manifest de secrets del conjunt de configuració, mai de text emmagatzemat.

La substitució es fa en una sola passada: cada token se substitueix una vegada i el text inserit mai no es torna a analitzar. La compilació falla si un token queda sense resoldre o si falta una credencial vinculada. Si té èxit, la compilació registra un Deployment Binding de les versions exactes utilitzades, de manera que la mateixa configuració es pugui reproduir més tard amb Torna a desplegar des de l'execució.

Nota: quan se superposen configuracions, la capa superior substitueix els arrays JSON sencers i mai no es combinen element per element.

Crideu-lo amb un Map, per exemple configChainSubstitute(file: 'app.json').
