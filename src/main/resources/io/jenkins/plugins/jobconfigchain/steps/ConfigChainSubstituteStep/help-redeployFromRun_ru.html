Відтворити конфігурацію, з якою було розгорнуто попередню збірку, для відкату: номер збірки цього завдання або <повна назва завдання>#<номер збірки>. Залиште порожнім для звичайного розгортання.

Результат байт-в-байт збігається з виходом тієї збірки, навіть якщо базові набори конфігурації відтоді змінилися. Якщо для тієї збірки немає записаної прив'язки розгортання (Deployment Binding), крок повідомляє про це в журналі збірки та використовує актуальну конфігурацію цього завдання замість того, щоб завершитися помилкою.
