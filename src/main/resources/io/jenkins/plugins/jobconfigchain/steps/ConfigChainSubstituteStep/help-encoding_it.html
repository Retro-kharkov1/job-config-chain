Set di caratteri usato per leggere il file di destinazione e per riscriverlo, ad esempio ISO-8859-1. Lascia vuoto per usare UTF-8; se il file non è UTF-8 valido, lo step registra un avviso, ripiega sul set di caratteri predefinito dell'agent e lo riscrive nello stesso set di caratteri. Un valore esplicito è rigoroso: nessun ripiego e nessun avviso, e un nome sconosciuto fa fallire la build. Un byte-order mark non viene né aggiunto né rimosso.
