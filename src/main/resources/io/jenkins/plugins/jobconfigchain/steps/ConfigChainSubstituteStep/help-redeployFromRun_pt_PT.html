Reproduz a configuração com a qual um build anterior foi implementado, para reversão: um número de build desta tarefa, ou <nome completo da tarefa>#<número do build>. Deixe vazio para uma implementação normal.

O resultado é idêntico, byte a byte, ao resultado desse build, mesmo que os conjuntos de configuração base tenham mudado entretanto. Se esse build não tiver um Deployment Binding registado, o passo indica-o no registo do build e utiliza a configuração atual desta tarefa em vez de falhar.
