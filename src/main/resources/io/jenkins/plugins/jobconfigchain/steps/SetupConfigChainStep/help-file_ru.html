Шлях до цільового файлу конфігурації відносно робочої області збірки. Зберігається для наступних викликів configChainValidate і configChainSubstitute у цій збірці, які тоді можуть його не вказувати; значення, задане в тих викликах, має пріоритет. Файл за межами робочої області лише дає попередження в журналі збірки.
