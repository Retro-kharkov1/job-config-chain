Remplace chaque jeton #{Dotted.Path}# du fichier cible par sa valeur issue de la configuration effective et réécrit le fichier. Les valeurs secrètes proviennent des identifiants Jenkins liés dans le manifeste des secrets du jeu de configuration, jamais d'un texte stocké.

La substitution se fait en une seule passe : chaque jeton est remplacé une fois et le texte inséré n'est jamais réanalysé. Le build échoue si un jeton reste non résolu ou si un identifiant lié est manquant. En cas de succès, le build enregistre un Deployment Binding des versions exactes utilisées, afin de pouvoir rejouer plus tard la même configuration avec Redéployer à partir de l'exécution.

Remarque : lorsque des configurations sont superposées, les tableaux JSON sont remplacés en bloc par la couche supérieure et jamais fusionnés élément par élément.

Appelez-la avec une Map, par exemple configChainSubstitute(file: 'app.json'). L'ancien nom configTemplateSubstitute fonctionne toujours comme alias obsolète.
