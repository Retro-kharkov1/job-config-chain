Eine genaue Versionsnummer fixieren, statt der aktuell aktiven Version. Leer lassen, um die aktive Version zu verwenden.

Ohne Konfigurationsschlüssel ist die Nummer eine Version der eigenen Konfiguration dieses Jobs; mit Konfigurationsschlüssel eine Version des betreffenden globalen Konfigurationssatzes. Eine ausdrückliche Version bewirkt, dass dieser Aufruf die Deployment Binding des Builds ignoriert, sodass eine bewusste einmalige Abweichung nie ändert, was der Build aufzeichnet.
