Pontos verziószám rögzítése az aktuálisan aktív helyett. Hagyja üresen az aktív verzió használatához.

Konfigurációs kulcs nélkül a szám a feladat saját konfigurációjának verziója; vele együtt az adott globális konfigurációs készlet verziója. A kifejezett verzió miatt ez a hívás figyelmen kívül hagyja a build telepítési kötését (Deployment Binding), így egy szándékos egyszeri felülírás soha nem változtatja meg, amit a build rögzít.
