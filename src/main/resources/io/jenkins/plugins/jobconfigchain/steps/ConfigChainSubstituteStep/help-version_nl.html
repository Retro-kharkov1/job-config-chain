Zet een exact versienummer vast in plaats van de momenteel actieve versie. Laat leeg om de actieve versie te gebruiken.

Zonder Configuratiesleutel is het nummer een versie van de eigen configuratie van deze job; met die sleutel is het een versie van die globale configuratieset. Een expliciete versie zorgt ervoor dat deze aanroep de uitrolbinding (Deployment Binding) van de build negeert, zodat een bewuste eenmalige afwijking nooit verandert wat de build vastlegt.
