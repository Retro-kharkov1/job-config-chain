Nahradí každý token #{Dotted.Path}# v cílovém souboru jeho hodnotou z efektivní konfigurace a soubor zapíše zpět. Hodnoty tajných údajů pocházejí z pověření Jenkinsu vázaných v manifestu tajných údajů sady konfigurace, nikdy z uloženého textu.

Dosazování probíhá v jednom průchodu: každý token se nahradí jednou a vložený text se již znovu neprohledává. Sestavení selže, pokud token zůstane nevyřešen nebo chybí vázané pověření. Při úspěchu sestavení zaznamená vazbu nasazení (Deployment Binding) s přesnými použitými verzemi, takže stejnou konfiguraci lze později přehrát volbou Znovu nasadit z běhu.

Poznámka: při vrstvení konfigurací jsou pole JSON překryvem nahrazena celá a nikdy se nesloučí prvek po prvku.

Volejte jej s mapou, například configChainSubstitute(file: 'app.json'). Dřívější název configTemplateSubstitute stále funguje jako zastaralý alias.
