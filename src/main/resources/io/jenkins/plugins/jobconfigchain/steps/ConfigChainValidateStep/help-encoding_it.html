Set di caratteri usato per leggere il file di destinazione, ad esempio ISO-8859-1. Lascia vuoto per leggerlo come UTF-8; se il file non è UTF-8 valido, lo step registra un avviso e ripiega sul set di caratteri predefinito dell'agent, così i file esistenti continuano a funzionare. Un valore esplicito è rigoroso: nessun ripiego e nessun avviso, e un nome sconosciuto fa fallire la build.
