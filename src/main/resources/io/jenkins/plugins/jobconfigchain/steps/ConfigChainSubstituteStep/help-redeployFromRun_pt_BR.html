Reproduz a configuração com a qual um build anterior foi implantado, para reversão: um número de build desta tarefa, ou <nome completo da tarefa>#<número do build>. Deixe vazio para uma implantação normal.

O resultado é idêntico byte a byte à saída desse build, mesmo que os conjuntos de configuração base tenham mudado desde então. Se esse build não tiver um Deployment Binding registrado, a etapa informa isso no log do build e usa a configuração atual desta tarefa em vez de falhar.
