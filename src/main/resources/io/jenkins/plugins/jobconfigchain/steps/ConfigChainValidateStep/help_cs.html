Zkontroluje cílový soubor proti efektivní konfiguraci před nasazením a nic nemění. Sestavení selže, pokud soubor obsahuje token #{Dotted.Path}#, který nemá odpovídající klíč (překlep nebo chybějící klíč). Klíče, které žádný token nepoužívá, se pouze hlásí jako varování.

Obvykle se volá těsně před configChainSubstitute se stejnými parametry, například configChainValidate(file: 'app.json').
