Épingler un numéro de version précis au lieu de la version actuellement active. Laissez vide pour utiliser la version active.

Sans Clé de configuration, le numéro est une version de la configuration propre à ce job ; avec elle, une version de ce jeu de configuration global. Une version explicite fait que cet appel ignore le Deployment Binding du build, de sorte qu'une dérogation ponctuelle délibérée ne modifie jamais ce que le build enregistre.
