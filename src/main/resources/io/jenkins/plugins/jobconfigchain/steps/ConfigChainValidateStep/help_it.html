Verifica il file di destinazione rispetto alla configurazione effettiva prima della distribuzione e non modifica nulla. La build fallisce se il file contiene un token #{Dotted.Path}# senza chiave corrispondente (errore di battitura o chiave mancante). Le chiavi che nessun token usa vengono solo segnalate come avviso.

Di solito viene chiamato subito prima di configChainSubstitute con gli stessi parametri, ad esempio configChainValidate(file: 'app.json'). Il nome precedente configTemplateValidate funziona ancora come alias obsoleto.
