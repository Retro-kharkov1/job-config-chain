Conjunto de caracteres usado para ler o arquivo de destino e gravá-lo de volta, por exemplo ISO-8859-1. Deixe vazio para usar UTF-8; se o arquivo não for UTF-8 válido, a etapa registra um aviso, recorre ao conjunto de caracteres padrão do agente e o grava de volta nesse mesmo conjunto. Um valor explícito é estrito: sem recurso alternativo nem aviso, e um nome desconhecido faz o build falhar. Uma marca de ordem de bytes não é adicionada nem removida.
