Jeu de caractères utilisé pour lire le fichier cible et le réécrire, par exemple ISO-8859-1. Laissez vide pour utiliser UTF-8 ; si le fichier n'est pas en UTF-8 valide, l'étape consigne un avertissement, se rabat sur le jeu de caractères par défaut de l'agent et le réécrit dans ce même jeu de caractères. Une valeur explicite est stricte : ni repli ni avertissement, et un nom inconnu fait échouer le build. Une marque d'ordre des octets n'est ni ajoutée ni supprimée.
