Nome di un set di configurazione globale (comune) da risolvere direttamente, indipendentemente dal fatto che faccia parte della catena di base di questo job.

Valido solo insieme a Usa un set di configurazione di base globale; senza di esso la build fallisce. La build fallisce anche se nessun set di configurazione globale ha questo nome. Una chiamata non può mai raggiungere la configurazione propria di un altro job.
