Comprueba el archivo de destino con la configuración efectiva antes del despliegue y no cambia nada. La compilación falla si el archivo contiene un token #{Dotted.Path}# sin clave correspondiente (errata o clave ausente). Las claves que ningún token usa solo se notifican como advertencia.

Normalmente se llama justo antes de configChainSubstitute con los mismos parámetros, por ejemplo configChainValidate(file: 'app.json').
