Numele unui set de configurare global (comun) care se rezolvă direct, indiferent dacă face parte sau nu din lanțul de bază al acestui job.

Valabil doar împreună cu Folosește un set de configurare de bază global; fără acesta build-ul eșuează. Dacă niciun set de configurare global nu are acest nume, build-ul eșuează de asemenea. Un apel nu poate ajunge niciodată la configurația proprie a altui job.
