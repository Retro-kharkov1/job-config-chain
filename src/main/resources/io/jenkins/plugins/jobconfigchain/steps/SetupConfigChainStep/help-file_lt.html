Tikslinio konfigūracijos failo kelias, nurodytas darbo srities atžvilgiu. Išsaugomas vėlesniems šio surinkimo configChainValidate ir configChainSubstitute iškvietimams, kurie tada gali jo nenurodyti; juose nurodyta reikšmė turi pirmenybę. Failas už darbo srities ribų sukelia tik įspėjimą surinkimo žurnale.
