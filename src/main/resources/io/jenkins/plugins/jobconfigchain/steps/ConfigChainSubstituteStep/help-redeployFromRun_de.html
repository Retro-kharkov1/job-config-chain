Die Konfiguration wiederverwenden, mit der ein früherer Build bereitgestellt wurde, für ein Rollback: eine Build-Nummer dieses Jobs oder <vollständiger Jobname>#<Build-Nummer>. Für eine normale Bereitstellung leer lassen.

Das Ergebnis ist byte-identisch mit der Ausgabe dieses Builds, auch wenn sich die Basis-Konfigurationssätze seitdem geändert haben. Hat dieser Build keine aufgezeichnete Deployment Binding, meldet der Schritt dies im Build-Protokoll und verwendet stattdessen die aktuelle Konfiguration dieses Jobs, statt fehlzuschlagen.
