Replaces every #{Dotted.Path}# token in the target file with its value from the effective configuration and writes the file back. Secret values come from the Jenkins credentials bound in the Config Set's secrets manifest, never from stored text.

Substitution is single-pass: each token is replaced once and inserted text is never scanned again. The build fails if a token stays unresolved or a bound credential is missing. On success the build records a Deployment Binding of the exact versions used, so the same configuration can be replayed later with Redeploy from run.

Note: when configurations are layered, JSON arrays are replaced wholesale by the overlay and never merged element by element.

Call it with a Map, for example configChainSubstitute(file: 'app.json'). The former name configTemplateSubstitute still works as a deprecated alias.
