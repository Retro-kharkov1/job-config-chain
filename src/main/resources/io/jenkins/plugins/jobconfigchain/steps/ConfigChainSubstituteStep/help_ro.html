Înlocuiește fiecare token #{Dotted.Path}# din fișierul țintă cu valoarea lui din configurația efectivă și scrie fișierul înapoi. Valorile secrete provin din acreditările Jenkins asociate în manifestul secretelor al setului de configurare, niciodată din text stocat.

Substituția se face într-o singură trecere: fiecare token este înlocuit o dată, iar textul inserat nu mai este scanat. Build-ul eșuează dacă un token rămâne nerezolvat sau dacă o acreditare asociată lipsește. La succes, build-ul înregistrează o asociere de desfășurare (Deployment Binding) cu versiunile exacte folosite, astfel încât aceeași configurație poate fi reluată ulterior cu Redeployează dintr-o rulare.

Notă: când configurațiile sunt stratificate, tablourile JSON sunt înlocuite integral de stratul superior și nu sunt niciodată îmbinate element cu element.

Apelați-l cu un Map, de exemplu configChainSubstitute(file: 'app.json'). Numele anterior configTemplateSubstitute funcționează în continuare ca alias depășit.
