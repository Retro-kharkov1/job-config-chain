Les jeux de configuration supprimés sont conservés avec tout leur historique des versions, afin qu'une suppression puisse être annulée.

Cochez Afficher les éléments supprimés pour les lister. Restaurer remet un jeu de configuration en service exactement tel qu'il était. Supprimer définitivement le détruit avec son historique et est irréversible ; l'action est refusée tant qu'un job mentionne encore ce jeu de configuration.
