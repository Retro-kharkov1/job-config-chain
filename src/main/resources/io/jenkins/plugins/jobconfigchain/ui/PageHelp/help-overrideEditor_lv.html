Šī redaktora saturs tiek piemērots virs apvienotajām bāzes konfigurācijas kopām. Rakstiet tikai to, kas atšķiras no bāzēm; katra izlaistā atslēga tiek mantota. JSON un YAML atslēgu no rezultāta var noņemt, iestatot to uz null.

Masīvi tiek aizstāti pilnībā. Objekti tiek apvienoti pa atslēgām, bet sarakstu (JSON masīvu, YAML secību vai atkārtotus vienlīmeņa elementus XML) nekad neapvieno pa elementiem. Ja bāzē ir [1, 2, 3] un šis redaktors iestata [4], rezultāts ir [4], nevis [1, 2, 3, 4]. Lai mainītu vienu saraksta elementu, atkārtojiet šeit visu sarakstu.
