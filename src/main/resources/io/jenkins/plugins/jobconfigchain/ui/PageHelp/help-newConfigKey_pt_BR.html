A chave de configuração dá nome a um novo conjunto de configuração global (comum). As tarefas se referem a ele por esse nome, na cadeia base de uma tarefa e no argumento configKey das etapas de pipeline.

O conjunto de configuração é criado quando você o salva pela primeira vez no editor dele, não quando clica em Abrir / Criar. O nome de um conjunto de configuração excluído permanece reservado até que ele seja restaurado ou excluído permanentemente.
