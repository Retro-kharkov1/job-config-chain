As linhas são os conjuntos de configuração base combinados, de cima para baixo; uma linha posterior prevalece quando duas linhas definem a mesma chave. O conteúdo próprio deste conjunto de configuração é aplicado em último lugar, sobre o resultado.

Chave de configuração: o conjunto de configuração global de onde esta linha obtém o conteúdo.

Modo: Ativa acompanha sempre a versão ativa atual desse conjunto de configuração, pelo que ativar lá uma nova versão altera o resultado aqui. Fixada congela a linha numa versão, que se mantém igual até alterar a fixação.

Versão fixada: o número de versão utilizado no modo Fixada. Não é utilizado no modo Ativa.
