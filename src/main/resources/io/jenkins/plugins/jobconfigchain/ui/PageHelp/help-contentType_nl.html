Het inhoudstype (JSON, XML of YAML) bepaalt hoe deze configuratieset wordt geparseerd, gevalideerd, opgemaakt en samengevoegd met de configuratiesets die erop voortbouwen.

Kies het eenmalig: het wordt voorgoed vergrendeld bij de eerste keer opslaan, en elke configuratieset die deze set opneemt, moet hetzelfde type gebruiken. Kies het formaat van de bestanden die uw pipelines gaan uitrollen.
