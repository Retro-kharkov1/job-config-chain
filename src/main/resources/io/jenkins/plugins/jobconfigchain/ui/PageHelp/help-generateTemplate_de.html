Zeigt eine kopierfertige Vorlage an, mit den Secret- und Ersetzungs-Tokens an Ort und Stelle, erzeugt aus der Konfiguration. Auf einer Job-Seite wird sie aus der effektiven (zusammengeführten) Konfiguration erzeugt, so wie sie in den Editoren steht, gespeichert oder nicht. Auf der Seite eines globalen Konfigurationssatzes wird sie nur aus der aktiven Version erzeugt, nicht aus ungespeicherten Änderungen. Durch das Generieren wird nichts gespeichert oder geändert.

Die Ausgabe ist schreibgeschützt; nutzen Sie In die Zwischenablage kopieren, um den Text zu übernehmen. Auf einer Job-Seite führt Zurück zur Dreispaltenansicht zur Bearbeitung zurück.
