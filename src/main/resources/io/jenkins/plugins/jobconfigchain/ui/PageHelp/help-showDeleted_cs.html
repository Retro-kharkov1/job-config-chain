Smazané sady konfigurace se uchovávají i s celou historií verzí, takže smazání lze vrátit.

Zaškrtnutím Zobrazit smazané je zobrazíte. Obnovit vrátí sadu konfigurace do provozu přesně tak, jak byla. Smazat trvale ji i s historií zničí a nelze to vrátit zpět; je zamítnuto, dokud nějaká úloha sadu konfigurace stále uvádí.
