このエディタの内容は、マージ済みのベース設定セットの上に適用されます。ベースと異なる部分だけを記述してください。省略したキーはすべて継承されます。JSON と YAML では、キーを null に設定すると結果から削除されます。

配列は丸ごと置き換えられます。オブジェクトはキーごとにマージされますが、リスト (JSON 配列、YAML シーケンス、XML の繰り返される兄弟要素) が要素ごとにマージされることはありません。ベースが [1, 2, 3] で、このエディタが [4] を設定した場合、結果は [1, 2, 3, 4] ではなく [4] になります。リストの 1 つの要素を変更するには、ここでリスト全体を繰り返し記述してください。
