Associa um valor secreto da configuração a uma credencial do Jenkins, para que o valor real nunca apareça no conjunto de configuração nem no respetivo histórico de versões.

Caminho com pontos: a localização do valor dentro do documento, com as chaves unidas por pontos, por exemplo database.password. Neste caminho, o editor só pode conter o espaço reservado literal __SECRET__; guardar qualquer outra coisa aí é rejeitado.

Credencial: a credencial do Jenkins que fornece o valor real quando um pipeline resolve a configuração. Aqui é guardado apenas o ID da credencial, nunca o segredo em si. A lista mostra as credenciais disponíveis para os administradores do Jenkins.

Associar credencial adiciona o caminho ou substitui a credencial se o caminho já estiver na lista.
