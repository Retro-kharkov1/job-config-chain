Sisu tüüp (JSON, XML või YAML) määrab, kuidas seda konfiguratsioonikomplekti parsitakse, valideeritakse, vormindatakse ja ühendatakse selle peale ehitavate konfiguratsioonikomplektidega.

Vali see üks kord: see lukustatakse lõplikult esimesel salvestamisel ja iga seda sisaldav konfiguratsioonikomplekt peab kasutama sama tüüpi. Vali vorming, milles failid sinu pipeline'id juurutavad.
