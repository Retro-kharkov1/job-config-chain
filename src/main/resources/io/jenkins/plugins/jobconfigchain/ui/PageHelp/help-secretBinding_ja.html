設定内のシークレット値を Jenkins の認証情報にバインドし、実際の値が設定セットやそのバージョン履歴に現れないようにします。

ドット区切りパス: ドキュメント内の値の場所を、キーをドットでつないで表したものです (例: database.password)。このパスにはエディタ上でリテラルのプレースホルダー __SECRET__ だけを指定できます。それ以外を保存しようとすると拒否されます。

認証情報: パイプラインが設定を解決するときに実際の値を供給する Jenkins の認証情報です。ここに保存されるのは認証情報 ID だけで、シークレット自体は保存されません。一覧には、Jenkins 管理者が利用できる認証情報が表示されます。

認証情報をバインドは、パスを追加するか、パスがすでに一覧にある場合は認証情報を置き換えます。
