이 편집기의 내용은 병합된 기본 구성 세트 위에 적용됩니다. 기본 구성과 다른 부분만 작성하세요. 생략한 키는 모두 상속됩니다. JSON과 YAML에서는 키를 null로 설정하면 결과에서 제거됩니다.

배열은 통째로 대체됩니다. 객체는 키별로 병합되지만 목록 (JSON 배열, YAML 시퀀스 또는 XML의 반복되는 형제 요소)은 요소별로 병합되지 않습니다. 기본 구성이 [1, 2, 3]이고 이 편집기가 [4]를 설정하면 결과는 [1, 2, 3, 4]가 아니라 [4]입니다. 목록의 요소 하나를 바꾸려면 여기에서 목록 전체를 다시 작성하세요.
