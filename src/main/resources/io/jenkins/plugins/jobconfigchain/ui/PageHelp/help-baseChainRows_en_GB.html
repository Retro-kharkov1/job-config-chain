The rows are the base Config Sets folded together, top to bottom; a later row wins where two rows set the same key. This Config Set's own content is applied last, on top of the result.

Config Key: the global Config Set this row takes content from.

Mode: Active always follows that Config Set's currently active version, so activating a new version there changes the result here. Pin freezes the row to one version, which stays the same until you change the pin.

Pinned version: the version number used in Pin mode. It is not used in Active mode.
