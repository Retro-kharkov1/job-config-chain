Le type de contenu (JSON, XML ou YAML) détermine la façon dont ce jeu de configuration est analysé, validé, formaté et fusionné avec les jeux de configuration qui s'appuient sur lui.

Choisissez-le une seule fois : il est verrouillé définitivement dès le premier enregistrement, et tout jeu de configuration qui inclut celui-ci doit utiliser le même type. Choisissez le format des fichiers que vos pipelines déploieront.
