The content of this editor is applied on top of the merged base Config Sets. Write only what differs from the bases; every key you leave out is inherited. In JSON and YAML, setting a key to null removes it from the result.

Arrays are replaced wholesale. Objects are merged key by key, but a list (a JSON array, a YAML sequence, or repeated sibling elements in XML) is never merged element by element. If a base has [1, 2, 3] and this editor sets [4], the result is [4], not [1, 2, 3, 4]. To change one element of a list, repeat the whole list here.
