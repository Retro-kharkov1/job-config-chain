Der Inhalt dieses Editors wird über die zusammengeführten Basis-Konfigurationssätze angewendet. Schreiben Sie nur, was sich von den Basen unterscheidet; jeder weggelassene Schlüssel wird geerbt. In JSON und YAML entfernt das Setzen eines Schlüssels auf null ihn aus dem Ergebnis.

Arrays werden vollständig ersetzt. Objekte werden Schlüssel für Schlüssel zusammengeführt, eine Liste (ein JSON-Array, eine YAML-Sequenz oder wiederholte Geschwisterelemente in XML) wird jedoch nie elementweise zusammengeführt. Hat eine Basis [1, 2, 3] und dieser Editor setzt [4], lautet das Ergebnis [4], nicht [1, 2, 3, 4]. Um ein Element einer Liste zu ändern, wiederholen Sie hier die gesamte Liste.
