Binds a secret value in the configuration to a Jenkins credential, so that the real value never appears in the Config Set or in its version history.

Dotted path: the location of the value inside the document, with the keys joined by dots, for example database.password. At this path the editor may only contain the literal placeholder __SECRET__; saving anything else there is rejected.

Credential: the Jenkins credential that supplies the real value when a pipeline resolves the configuration. Only the credential ID is stored here, never the secret itself. The list shows the credentials available to Jenkins administrators.

Bind credential adds the path, or replaces the credential if the path is already listed.
