Le righe sono i set di configurazione di base uniti, dall'alto in basso; una riga successiva prevale dove due righe impostano la stessa chiave. Il contenuto proprio di questo set di configurazione viene applicato per ultimo, sopra il risultato.

Chiave di configurazione: il set di configurazione globale da cui questa riga prende il contenuto.

Modalità: Attiva segue sempre la versione attualmente attiva di quel set di configurazione, quindi attivare lì una nuova versione cambia il risultato qui. Fissata blocca la riga su una versione, che resta la stessa finché non modifichi il blocco.

Versione fissata: il numero di versione usato in modalità Fissata. Non viene usato in modalità Attiva.
