Innholdstypen (JSON, XML eller YAML) bestemmer hvordan dette konfigurasjonssettet tolkes, valideres, formateres og slås sammen med konfigurasjonssettene som bygger på det.

Velg den én gang: den låses for godt ved første lagring, og alle konfigurasjonssett som inkluderer dette, må bruke den samme typen. Velg formatet på filene pipelinene dine skal distribuere.
