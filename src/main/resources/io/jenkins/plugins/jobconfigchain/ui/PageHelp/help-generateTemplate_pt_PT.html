Mostra um modelo pronto para copiar e colar, com os tokens de segredo e de substituição no lugar, construído a partir da configuração. Na página de uma tarefa, é construído a partir da configuração efetiva (combinada) tal como está nos editores, guardada ou não. Na página de um conjunto de configuração global, é construído apenas a partir da versão ativa, não das edições não guardadas. A geração não guarda nem altera nada.

O resultado é só de leitura; utilize Copiar para a área de transferência para obter o texto. Na página de uma tarefa, Voltar à vista de 3 painéis regressa à edição.
