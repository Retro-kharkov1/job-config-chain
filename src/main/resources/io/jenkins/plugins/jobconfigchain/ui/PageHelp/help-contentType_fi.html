Sisältötyyppi (JSON, XML tai YAML) määrää, miten tämä asetusjoukko jäsennetään, tarkistetaan, muotoillaan ja yhdistetään sen päälle rakentuviin asetusjoukkoihin.

Valitse se kerran: se lukitaan lopullisesti ensimmäisellä tallennuksella, ja jokaisen tämän sisältävän asetusjoukon on käytettävä samaa tyyppiä. Valitse sellaisten tiedostojen muoto, joita pipelinesi ottavat käyttöön.
