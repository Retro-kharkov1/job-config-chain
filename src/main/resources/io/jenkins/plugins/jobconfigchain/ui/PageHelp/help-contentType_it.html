Il tipo di contenuto (JSON, XML o YAML) determina come questo set di configurazione viene analizzato, validato, formattato e unito ai set di configurazione che si basano su di esso.

Sceglilo una sola volta: viene bloccato per sempre dal primo salvataggio e ogni set di configurazione che include questo deve usare lo stesso tipo. Scegli il formato dei file che le tue pipeline distribuiranno.
