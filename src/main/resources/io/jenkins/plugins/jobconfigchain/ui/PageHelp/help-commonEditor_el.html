Το περιεχόμενο αυτού του καθολικού Συνόλου διαμόρφωσης. Η σύνταξη ελέγχεται καθώς πληκτρολογείτε και η Αποθήκευση απορρίπτεται όσο είναι μη έγκυρο. Κάθε Αποθήκευση δημιουργεί νέα έκδοση· η Αποθήκευση και ενεργοποίηση κάνει επιπλέον αυτή την έκδοση ενεργή, που είναι αυτή που λαμβάνουν οι εργασίες που ακολουθούν την ενεργή έκδοση.

Όταν εργασίες χτίζονται πάνω σε αυτό το Σύνολο διαμόρφωσης, οι παρακάμψεις τους εφαρμόζονται πάνω του. Οι πίνακες αντικαθίστανται συνολικά σε αυτή τη συγχώνευση: μια λίστα σε μια παράκαμψη αντικαθιστά εξ ολοκλήρου τη λίστα αυτού του Συνόλου διαμόρφωσης και δεν συγχωνεύεται ποτέ στοιχείο προς στοιχείο.

Η Δημιουργία προτύπου εμφανίζει ένα έτοιμο για αντιγραφή-επικόλληση πρότυπο, με τα διακριτικά μυστικών και αντικατάστασης στη θέση τους, που δημιουργείται μόνο από την ΕΝΕΡΓΗ έκδοση και όχι από μη αποθηκευμένες αλλαγές. Είναι μόνο για ανάγνωση και δεν αλλάζει τίποτα.
