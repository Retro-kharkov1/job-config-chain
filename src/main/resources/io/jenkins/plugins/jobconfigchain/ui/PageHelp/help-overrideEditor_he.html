תוכן העורך הזה מוחל מעל ערכות התצורה הבסיסיות הממוזגות. כתוב רק את מה שנבדל מהבסיסים; כל מפתח שתשמיט עובר בירושה. ב-JSON וב-YAML, קביעת מפתח ל-null מסירה אותו מהתוצאה.

מערכים מוחלפים כולם. אובייקטים ממוזגים מפתח אחר מפתח, אבל רשימה (מערך JSON, רצף YAML או רכיבי אחים חוזרים ב-XML) לעולם אינה ממוזגת איבר אחר איבר. אם בבסיס יש [1, 2, 3] והעורך הזה קובע [4], התוצאה היא [4] ולא [1, 2, 3, 4]. כדי לשנות איבר אחד ברשימה, חזור כאן על הרשימה כולה.
