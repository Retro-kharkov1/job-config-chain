Le contenu de cet éditeur est appliqué par-dessus les jeux de configuration de base fusionnés. N'écrivez que ce qui diffère des bases ; toute clé omise est héritée. En JSON et en YAML, définir une clé à null la supprime du résultat.

Les tableaux sont remplacés en bloc. Les objets sont fusionnés clé par clé, mais une liste (un tableau JSON, une séquence YAML ou des éléments frères répétés en XML) n'est jamais fusionnée élément par élément. Si une base contient [1, 2, 3] et que cet éditeur définit [4], le résultat est [4], et non [1, 2, 3, 4]. Pour modifier un seul élément d'une liste, répétez ici la liste entière.
