Bindet einen Secret-Wert in der Konfiguration an Jenkins-Zugangsdaten, sodass der echte Wert weder im Konfigurationssatz noch in dessen Versionsverlauf erscheint.

Punktpfad: die Position des Werts im Dokument, wobei die Schlüssel durch Punkte verbunden sind, zum Beispiel database.password. An diesem Pfad darf der Editor nur den literalen Platzhalter __SECRET__ enthalten; alles andere wird beim Speichern abgelehnt.

Zugangsdaten: die Jenkins-Zugangsdaten, die den echten Wert liefern, wenn eine Pipeline die Konfiguration auflöst. Hier wird nur die ID der Zugangsdaten gespeichert, nie das Secret selbst. Die Liste zeigt die Zugangsdaten, die für Jenkins-Administratoren verfügbar sind.

Zugangsdaten binden fügt den Pfad hinzu oder ersetzt die Zugangsdaten, wenn der Pfad bereits aufgeführt ist.
