O conteúdo deste editor é aplicado por cima dos conjuntos de configuração base mesclados. Escreva apenas o que difere das bases; toda chave omitida é herdada. Em JSON e YAML, definir uma chave como null a remove do resultado.

Os arrays são substituídos por inteiro. Os objetos são mesclados chave por chave, mas uma lista (um array JSON, uma sequência YAML ou elementos irmãos repetidos em XML) nunca é mesclada elemento por elemento. Se uma base tiver [1, 2, 3] e este editor definir [4], o resultado será [4], não [1, 2, 3, 4]. Para alterar um elemento de uma lista, repita aqui a lista inteira.
