Conținutul acestui set de configurare global. Sintaxa este verificată pe măsură ce tastați, iar o salvare este refuzată cât timp conținutul este invalid. Fiecare salvare creează o versiune nouă; Salvează și activează face și din acea versiune versiunea activă, pe care o primesc joburile ce urmăresc versiunea activă.

Când joburile se bazează pe acest set de configurare, suprascrierile lor se aplică peste el. În această îmbinare tablourile sunt înlocuite integral: o listă dintr-o suprascriere înlocuiește complet lista acestui set de configurare și nu este niciodată îmbinată element cu element.

Generează șablon afișează un șablon gata de copiat, cu tokenurile de secret și de substituție, construit doar din versiunea ACTIVĂ, nu din modificările nesalvate. Este doar pentru citire și nu modifică nimic.
