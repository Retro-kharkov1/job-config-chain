Gelöschte Konfigurationssätze werden samt ihrem gesamten Versionsverlauf aufbewahrt, sodass ein Löschen rückgängig gemacht werden kann.

Aktivieren Sie Gelöschte anzeigen, um sie aufzulisten. Wiederherstellen nimmt einen Konfigurationssatz genau so wieder in Betrieb, wie er war. Endgültig löschen vernichtet ihn samt Verlauf und kann nicht rückgängig gemacht werden; es wird verweigert, solange noch ein Job den Konfigurationssatz nennt.
