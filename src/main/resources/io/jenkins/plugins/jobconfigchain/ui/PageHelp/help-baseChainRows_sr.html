Редови су основни скупови конфигурација спојени одозго надоле; каснији ред побеђује тамо где два реда постављају исти кључ. Сопствени садржај овог скупа конфигурација примењује се последњи, преко резултата.

Кључ конфигурације: глобални скуп конфигурација из којег ред преузима садржај.

Режим: Активна увек прати тренутно активну верзију тог скупа конфигурација, па активирање нове верзије тамо мења резултат овде. Фиксирана замрзава ред на једној верзији, која остаје иста док не промените фиксирање.

Фиксирана верзија: број верзије који се користи у режиму Фиксирана. Не користи се у режиму Активна.
