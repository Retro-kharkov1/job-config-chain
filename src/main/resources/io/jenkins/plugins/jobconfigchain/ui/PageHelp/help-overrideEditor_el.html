Το περιεχόμενο αυτού του επεξεργαστή εφαρμόζεται πάνω από τα συγχωνευμένα βασικά Σύνολα διαμόρφωσης. Γράψτε μόνο ό,τι διαφέρει από τις βάσεις· κάθε κλειδί που παραλείπετε κληρονομείται. Σε JSON και YAML, ο ορισμός ενός κλειδιού σε null το αφαιρεί από το αποτέλεσμα.

Οι πίνακες αντικαθίστανται συνολικά. Τα αντικείμενα συγχωνεύονται κλειδί προς κλειδί, αλλά μια λίστα (πίνακας JSON, ακολουθία YAML ή επαναλαμβανόμενα αδελφά στοιχεία σε XML) δεν συγχωνεύεται ποτέ στοιχείο προς στοιχείο. Αν μια βάση έχει [1, 2, 3] και αυτός ο επεξεργαστής ορίζει [4], το αποτέλεσμα είναι [4] και όχι [1, 2, 3, 4]. Για να αλλάξετε ένα στοιχείο μιας λίστας, επαναλάβετε εδώ ολόκληρη τη λίστα.
