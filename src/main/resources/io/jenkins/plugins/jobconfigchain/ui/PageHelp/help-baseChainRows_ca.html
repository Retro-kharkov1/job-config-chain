Les files són els conjunts de configuració base combinats, de dalt a baix; una fila posterior preval quan dues files defineixen la mateixa clau. El contingut propi d'aquest conjunt de configuració s'aplica l'últim, damunt del resultat.

Clau de configuració: el conjunt de configuració global del qual aquesta fila pren el contingut.

Mode: Activa segueix sempre la versió activa actual d'aquest conjunt de configuració, de manera que activar-hi una versió nova canvia el resultat aquí. Fixada congela la fila en una versió, que continua igual fins que canvieu la fixació.

Versió fixada: el número de versió utilitzat en el mode Fixada. No s'utilitza en el mode Activa.
