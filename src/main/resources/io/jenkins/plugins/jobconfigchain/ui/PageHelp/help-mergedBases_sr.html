Преглед основног ланца спојеног заједно, само за читање, без сопственог преписивања овог скупа конфигурација. Ажурира се док уређујете основни ланац.

Низови се замењују у целини: где две основе постављају листу, листа касније основе у потпуности замењује ранију; листе се никада не комбинују елемент по елемент.
