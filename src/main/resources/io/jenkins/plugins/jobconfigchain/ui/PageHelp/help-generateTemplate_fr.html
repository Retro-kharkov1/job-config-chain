Affiche un modèle prêt à copier-coller, avec les jetons de secrets et de substitution en place, construit à partir de la configuration. Sur la page d'un job, il est construit à partir de la configuration effective (fusionnée) telle qu'elle figure dans les éditeurs, enregistrée ou non. Sur la page d'un jeu de configuration global, il est construit à partir de la seule version active, et non des modifications non enregistrées. Sa génération n'enregistre ni ne modifie rien.

Le résultat est en lecture seule ; utilisez Copier dans le presse-papiers pour récupérer le texte. Sur la page d'un job, Retour à la vue à 3 panneaux permet de revenir à la modification.
