Conținutul acestui editor se aplică peste seturile de configurare de bază îmbinate. Scrieți doar ce diferă de baze; orice cheie omisă este moștenită. În JSON și YAML, setarea unei chei la null o elimină din rezultat.

Tablourile sunt înlocuite integral. Obiectele sunt îmbinate cheie cu cheie, dar o listă (un tablou JSON, o secvență YAML sau elemente frate repetate în XML) nu este niciodată îmbinată element cu element. Dacă o bază are [1, 2, 3], iar acest editor setează [4], rezultatul este [4], nu [1, 2, 3, 4]. Pentru a schimba un element al unei liste, repetați aici întreaga listă.
