Šio redaktoriaus turinys taikomas virš sujungtų bazinių konfigūracijos rinkinių. Rašykite tik tai, kuo skiriasi nuo bazių; kiekvienas praleistas raktas paveldimas. JSON ir YAML raktą iš rezultato pašalinsite nustatę jį į null.

Masyvai pakeičiami visiškai. Objektai sujungiami raktas po rakto, tačiau sąrašas (JSON masyvas, YAML seka arba pasikartojantys vieno lygio elementai XML) niekada nesujungiamas po elementą. Jei bazėje yra [1, 2, 3], o šis redaktorius nustato [4], rezultatas yra [4], o ne [1, 2, 3, 4]. Norėdami pakeisti vieną sąrašo elementą, pakartokite visą sąrašą čia.
