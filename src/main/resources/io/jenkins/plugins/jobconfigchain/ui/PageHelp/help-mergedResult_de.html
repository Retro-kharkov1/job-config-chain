Schreibgeschützte Vorschau der endgültigen Konfiguration: die zusammengeführten Basen mit Ihrer darüber angewendeten Überschreibung. Dies erhält eine Pipeline, wenn sie diesen Konfigurationssatz auflöst.

Arrays werden vollständig ersetzt: Eine in der Überschreibung gesetzte Liste ersetzt die Liste der Basis komplett und wird nie elementweise zusammengeführt. Ist die Überschreibung derzeit ungültig, bleibt das letzte gültige Ergebnis sichtbar und wird als veraltet markiert.
