El contingut d'aquest editor s'aplica damunt dels conjunts de configuració base combinats. Escriviu només el que difereix de les bases; tota clau que ometeu s'hereta. En JSON i YAML, establir una clau a null l'elimina del resultat.

Els arrays se substitueixen sencers. Els objectes es combinen clau per clau, però una llista (un array JSON, una seqüència YAML o elements germans repetits en XML) mai no es combina element per element. Si una base té [1, 2, 3] i aquest editor estableix [4], el resultat és [4], no [1, 2, 3, 4]. Per canviar un element d'una llista, repetiu aquí la llista sencera.
