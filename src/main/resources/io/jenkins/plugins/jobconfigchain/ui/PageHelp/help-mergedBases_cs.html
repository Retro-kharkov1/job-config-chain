Náhled základního řetězce složeného dohromady, pouze pro čtení, bez vlastního přepsání této sady konfigurace. Aktualizuje se při úpravách základního řetězce.

Pole se nahrazují celá: když dvě základny nastavují seznam, seznam pozdější základny nahradí dřívější celý; seznamy se nikdy nesloučí prvek po prvku.
