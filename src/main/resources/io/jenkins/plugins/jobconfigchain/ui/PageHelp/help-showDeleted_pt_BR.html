Os conjuntos de configuração excluídos são mantidos, com todo o histórico de versões, para que uma exclusão possa ser desfeita.

Marque Mostrar excluídos para listá-los. Restaurar devolve um conjunto de configuração ao serviço exatamente como estava. Excluir permanentemente o destrói junto com o histórico e não pode ser desfeito; é recusado enquanto alguma tarefa ainda citar o conjunto de configuração.
