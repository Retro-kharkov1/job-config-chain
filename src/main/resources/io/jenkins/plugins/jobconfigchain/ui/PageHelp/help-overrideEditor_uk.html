Вміст цього редактора застосовується поверх злитих базових наборів конфігурації. Записуйте лише те, що відрізняється від базових наборів; кожен пропущений ключ успадковується. У JSON та YAML значення null для ключа прибирає його з результату.

Масиви замінюються цілком. Об'єкти зливаються за ключами, але список (масив JSON, послідовність YAML або повторювані сусідні елементи в XML) ніколи не зливається поелементно. Якщо в базовому наборі [1, 2, 3], а в цьому редакторі задано [4], результатом буде [4], а не [1, 2, 3, 4]. Щоб змінити один елемент списку, повторіть тут увесь список.
