O conteúdo deste conjunto de configuração global. A sintaxe é verificada enquanto você digita, e o salvamento é recusado enquanto ela for inválida. Cada salvamento cria uma nova versão; Salvar e ativar também torna essa versão a ativa, que é a que as tarefas que acompanham a versão ativa recebem.

Quando há tarefas construídas sobre este conjunto de configuração, as sobrescritas delas são aplicadas por cima. Os arrays são substituídos por inteiro nessa mesclagem: uma lista em uma sobrescrita substitui totalmente a lista deste conjunto de configuração e nunca é mesclada elemento por elemento.

Gerar modelo mostra um modelo pronto para copiar e colar, com os tokens de segredo e de substituição no lugar, construído somente a partir da versão ATIVA, não das edições não salvas. É somente leitura e não altera nada.
