Borttagna konfigurationsuppsättningar bevaras, med hela sin versionshistorik, så att en borttagning kan ångras.

Markera Visa borttagna för att lista dem. Återställ sätter tillbaka en konfigurationsuppsättning i drift precis som den var. Ta bort permanent förstör den och dess historik och kan inte ångras; det avvisas så länge ett jobb fortfarande nämner konfigurationsuppsättningen.
