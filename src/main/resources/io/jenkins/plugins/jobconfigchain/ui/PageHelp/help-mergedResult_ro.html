Previzualizare doar pentru citire a configurației finale: bazele îmbinate cu suprascrierea dvs. aplicată peste ele. Aceasta este ceea ce primește un pipeline când rezolvă acest set de configurare.

Tablourile sunt înlocuite integral: o listă setată în suprascriere înlocuiește complet lista bazei și nu este niciodată îmbinată element cu element. Dacă suprascrierea este invalidă în prezent, ultimul rezultat valid rămâne pe ecran și este marcat ca vechi.
